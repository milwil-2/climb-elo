How it works.

For each simulation we draw a performance score per athlete from N(μ, σ·k), rank them, and tally the placements. Repeat 10,000 times; report the fraction.

scorei  ←  N(μi, σi · 1.2) + ε
rank  ←  argsort(−score)
P(win)i  ←  #{ranki = 1} / Nsims
