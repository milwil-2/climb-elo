Example

Fetch the top-10 Boulder men. No auth header, no rate limit you'll hit.

# shell
curl 'https://climbing-elo.app/api/v1/leaderboard?discipline=boulder&gender=M&limit=10'

# response
{
  "discipline": "boulder",
  "gender": "M",
  "total": 120,
  "items": [
    { "rank": 1, "name": "...", "mu": 1847, "sigma": 62 },
    // ...
  ]
}
POST /api/v1/projections

Run Monte Carlo for a custom set of athletes. Results cached 1h.

curl -X POST '.../api/v1/projections' \
  -H 'Content-Type: application/json' \
  -d '{"discipline":"lead","athlete_ids":[1,2,3]}'
